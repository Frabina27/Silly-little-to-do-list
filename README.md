# To-Do List

A simple To-Do List app that helps you organize your daily tasks. Built with HTML, CSS, and JavaScript, it allows you to add, complete, and delete tasks easily in a clean interface.

---

## Features
- Add new tasks  
- Mark tasks as complete  
- Delete tasks  
- Saves tasks in local storage  

---

## Technologies Used
- HTML  
- CSS  
- JavaScript
